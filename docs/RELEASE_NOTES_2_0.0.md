# SAOViVO 2.0

SAOViVO 2.0 convierte archivos MP4 locales, videos y playlists de YouTube en una cola que se transmite como un vivo continuo desde Windows.

## Una nueva implementación con historia

SAOViVO nació en 2022. Esta versión es una reimplementación completa de escritorio construida en Electron y reemplaza la arquitectura histórica separada en Go y React. El código anterior se conserva en el historial y en un tag `legacy-2023`, pero no representa la aplicación vigente.

SAOViVO 2.0 no garantiza migración automática de colas o configuraciones de instalaciones anteriores. **SAOViVO Cloud 1.0** es el nombre reservado para el prototipo histórico de bloques de datos y clima; no forma parte de esta descarga.

## Qué incluye

- archivos MP4 locales sin depender de `yt-dlp`;
- videos, playlists, Shorts y fuentes Live de YouTube;
- colas mixtas y edición de pendientes durante el vivo;
- loop, navegación, preparación en segundo plano y reconexión;
- instalador y portable para Windows 10/11 de 64 bits;
- logs operativos sanitizados para diagnóstico.

## Descargas

- `SAOViVO-Setup-2.0.0.exe`: instalación asistida.
- `SAOViVO-2.0.0-portable.exe`: ejecución portable.

Esta primera publicación puede mostrar `Editor desconocido` porque el certificado de firma se solicitará a SignPath Foundation después de publicar el proyecto. Verificá los hashes SHA-256 incluidos en este Release.
