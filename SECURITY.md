# Seguridad

## Reportar una vulnerabilidad

No publiques stream keys, credenciales, logs sin revisar ni vulnerabilidades explotables en un Issue público.

Enviá el reporte a `saovivoapp@gmail.com` con:

- versión de SAOViVO;
- versión de Windows;
- descripción y pasos mínimos para reproducir;
- impacto observado;
- logs sanitizados, si son necesarios.

El proyecto confirmará la recepción y coordinará una divulgación responsable. Los errores funcionales sin información sensible pueden reportarse en GitHub Issues.

## Alcance

SAOViVO protege la stream key con las funciones de credenciales de Windows y sanitiza datos sensibles conocidos antes de escribir logs. Ningún mecanismo elimina la necesidad de mantener Windows actualizado y proteger la cuenta de YouTube.
