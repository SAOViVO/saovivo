# Contribuir a SAOViVO

Gracias por colaborar con SAOViVO.

1. Abrí un Issue con el problema o propuesta antes de realizar un cambio grande.
2. Creá una rama específica y mantené el cambio acotado.
3. Ejecutá `npm ci` y `npm test`.
4. Explicá el impacto para usuarios y las verificaciones realizadas en el Pull Request.

Los cambios visuales deben respetar `docs/brand/IDENTIDAD_BASE.md`. No se aceptan reinterpretaciones del Logo, la Leyenda, la paleta o la grafía `SAOViVO` sin una decisión previa documentada.

No incluyas credenciales, stream keys, videos privados, logs sin sanitizar ni archivos de usuarios.
